# 1.3 About the STM32 Cortex-M4 processor and core peripherals

- a high performance 32-bit processor
- processing performance 
	- combined with fast interrupt handling
- enhanced system debug (bp & trace)
- efficient processor core
- ultra-low power consumption 
	- with integrated sleep modes
- integrated memory protection unit ([[MPU]])
