# Runnable
## [[AUTOSAR]]

- Каждый [[SWC]] включает в себя ряд исполняемых функций ([[em/Runnable]])
	- это и есть, тот небольшой участок кода, который вы должны написать руками
- [[em/Runnable|Runnable]] будут вызываться по определенным событиям — при старте, периодически, по прерыванию и прочее.
