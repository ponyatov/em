# 1. подключаем и исследуем плату
https://www.linux.org.ru/articles/development/17345778

Примеры написаны для популярной платы blue [[pillF103]], построенной на микроконтроллере [[STM32F103C8T6]].

- Подключить плату к компьютеру и убедиться, что появляются новые устройства
- Написать простейшую программу на ассемблере, которая в цикле прибавляет регистр
	- скомпилировать
	- прошить
	- пронаблюдать работу
- Помигать диодом (на ассемблере же).
- Написать простейшую программу на [[Cpp/C|C]], которая в цикле прибавляет значение глобальной переменной
- Помигать диодом на С (дальше всё на С).
- Переписать мигание с использованием таймера, чтобы поближе познакомиться с прерываниями.
- Сказать внешнему миру «Hello world» через [[hw/UART/UART|UART]]
- Переписать «Hello world» с помощью [[CMSIS]], уже с пониманием того, что там происходит.
