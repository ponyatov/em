# CCM RAM
## Core-Coupled Memory

- [[STM32F3]]
- [[STM32F4]]
	- [[CCMDATARAM_BASE]]

- может быть использована для любых целей, кроме исполнения из него программного кода или [[hw/DMA|DMA]]

- оперативная память для хранения констант, таблиц и стека

- По умолчанию эта память обесточена, чтоб электричество не трескала
