# [[Infeneon]] miniWiggler

https://www.infineon.com/cms/en/product/evaluation-boards/kit_dap_miniwiggler_usb/

The [[miniWiggler]] is [[Infineon]]’s high performance and cost-efficient debugging tool for the future. On the host side, it has an [[usb/USB|USB]] interface, which is available on every computer. On the device side, the communication goes over Infineon 10-pin [[DAP]] or 16-pin [[OCDSL1]] interfaces. The miniWiggler has been designed specifically to work in combination with Infineon’s Debug Access Software ([[DAS]]).
