- ARMv7E-M
	- 6-stage pipeline with branch speculation
- optional double-precision FPU
	- [[FPv5]]
- Optional CPU cache:
	- 0 to 64 KB instruction-[[icache]]
	- 0 to 64 KB data-[[hw/arch/dcache]]
	- each with optional [[ECC]].
