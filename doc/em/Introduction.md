# Introduction
## [[The Embedded Rust Book]]
#STM32 

An introductory book about using the [[Rust]] Programming Language on "[[bare metal]]" embedded systems, such as [[hw/microcontroller|microcontroller]]s.

manual provides information for application and system-level software developers

It gives a full description of the 
- processor programming model, 
- instruction set and 
- core peripherals

The [[Cortex-M4]] processor core used in [[STM32F3]] Series, [[STM32F4]] Series, [[STM32G4]] Series, [[STM32H745]]/755 and [[STM32H747]]/757 Lines, [[STM32L4]] Series, [[STM32L4+]] Series, [[STM32WB]] Series, [[STM32WL]] Series and [[STM32MP1]] Series

high performance 32-bit processor

## Scope
https://docs.rust-embedded.org/book/#scope

The goals of this book are:
- Get developers up to speed with [[Embedded Rust]] development
	- How to set up a development environment
- current best practices about using Rust for embedded
	- how to write more correct embedded software
- cookbook
	- How do I [[mix C and Rust]] in a single project?

uses the ARM [[hw/arch/Cortex-M|Cortex-M]] architecture as the most popular
